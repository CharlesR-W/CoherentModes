The question

Which inputs does a network treat the same, at which layer, and since when in training? I ask this without labels: only the network's own activations go in.

Activation cells

  • Stefan Heimersheim and collaborators observed that a layer's activation space behaves as if tiled into Voronoi-like cells.
  • If the rest of the network computes nearly the same thing everywhere in a cell, which cell an input lands in carries most of what the rest of the network uses.
  • At that layer the network then behaves like a machine with discrete states, which could in principle be read off.

Find the groups, not the walls

  • Measuring boundaries directly does not scale, and the data only sample the space, so most of any boundary is never seen.
  • Instead I ask which inputs the network treats as interchangeable. A cell is then a group of inputs that few neighbourhood links leave.
  • Finding such groups is what spectral clustering does: one similarity matrix per layer, one forward pass per input and checkpoint, no Jacobians.
Takeaway: instead of mapping where the network's behaviour changes, I look for groups of inputs that neighbourhood links rarely leave, at a cost that grows with the number of inputs rather than the size of the network.
The cell picture, and the working hypothesis that inside a cell the downstream output is close to the average over nearby inputs (a limited form of harmonic label propagation), are motivation. A first labelled test has been designed but not yet run; until it has, this is not a result.
