Coherent sets across layer blocks · ResNet-20 on CIFAR-10 (exploratory)

Rows: training checkpoints. Columns: residual-stream sites (stem, block outputs b1–b9, global-average pool, logits). Each cell is an AlignedUMAP (aligned across sites within a checkpoint, Procrustes-aligned across checkpoints) of the same 2,000 test images (200 per class) from that site's centred-cosine geometry. Pick a source checkpoint and a block of sites L′..L: the leading eigenvectors of that block's averaged vMF diffusion operator (a dynamic-Laplacian discretisation) colour every cell, so you can follow a set the block treats as coherent through other layers and other times. Click a cell to set the source checkpoint and L; shift-click to set L′. Click a legend entry to isolate that set.
